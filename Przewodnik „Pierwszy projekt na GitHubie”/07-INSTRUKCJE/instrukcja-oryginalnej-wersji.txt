PRZEWODNIK „PIERWSZY PROJEKT NA GITHUBIE” — Deividas Dirma

1. Rozpakuj CAŁY katalog projektu.
2. Otwórz index.html — aplikacja działa bez instalowania bibliotek i bez internetu.
3. Wczytany przykład ma 50%. Dodaj instrukcję uruchomienia i kliknij Sprawdź:
   wynik 66,7%, porównanie +1, problem R5 znika.
4. Sekcje „Działanie algorytmów” i „Porównania…” rozwijają się kliknięciem.
5. Zapisuj pracę przez Eksport JSON — odświeżenie strony resetuje dane.

TESTY: z Node.js 20+ w katalogu projektu uruchom npm test.
POMIARY: npm run benchmark.
OPCJONALNY SERWER: npm start → http://127.0.0.1:8080.
Nie jest potrzebne npm install.

DOKUMENTY:
docs/dokumentacja.pdf — dokładnie 10 stron.
docs/prezentacja.pdf — dokładnie 10 slajdów.
docs/prezentacja.html — lokalna prezentacja w przeglądarce, sterowanie strzałkami.

README.md — instrukcja, model danych, algorytmy i źródła.

WAŻNE PRZED ODDANIEM:
Obowiązkowe repozytorium GitHub NIE ZOSTAŁO OPUBLIKOWANE — konto nie jest połączone.
Po publikacji uzupełnij prawdziwy URL w dokumentacji i prezentacji, podaj link
w Dzienniku i oznaczenie commitu. Zapewnij prowadzącemu dostęp.
Aplikacja nie musi logować się do GitHuba ani korzystać z GitHub API.
Przećwicz i zrozum kod oraz opisz swoje faktycznie wykonane zmiany i wsparcie AI.
